# Media placeholder (ChemiVerse)

Letakkan aset di sini sesuai rencana bertahap.

- `images/` — gambar ilustrasi/foto (PNG/JPG/WebP/SVG). Gunakan nama deskriptif, mis. `modul-1-indikator-asam-basa.jpg`.
- `videos/` — video lokal (MP4/WebM) atau simpan referensi embed di komponen/konten.

Komponen media (tahap berikutnya) akan mendukung path lokal (`/media/...`) dan embed URL dengan allowlist.
